# ZeroClaw 心跳与定时任务配置

> PicoClaw 风格定时配置。ZeroClaw gateway 按此配置执行周期性巡检和状态报告。

---

## 定时心跳

| 项目 | 值 |
|------|-----|
| 间隔 | 30 秒 |
| 动作 | 检查 MCP server 连接是否存活 |
| 超时 | 5 秒 |
| 未响应处理 | 记录告警，尝试重连（最多 3 次） |

## 定期任务

### 1. 系统健康报告

- **频率**: 每 5 分钟
- **动作**: `memory_search` → 汇总最近系统状态
- **输出**: 写入 agent/MEMORY.md 的 `## Health` 节

### 2. 技能目录同步

- **频率**: 每 30 分钟
- **动作**: 调用 `mcp.servers[askme]` 重新拉取 tools/list
- **目的**: 及时反映 Askme 侧新增或移除的技能

### 3. 连接保活

- **频率**: 每 15 秒
- **动作**: 发送空 ping 到 MCP server
- **超时**: 3 秒
- **连续失败阈值**: 3 次 → 触发重连

---

## 重连策略

```
第 1 次失败 -> 立即重试
第 2 次失败 -> 等待 2 秒后重试
第 3 次失败 -> 等待 5 秒后重试
3 次以上失败 -> 等待 30 秒后重试，记录严重告警
```

## 告警通知

所有告警写入 `data/logs/zeroclaw-bridge.log`，格式：

```
[时间] [级别] [模块] 消息
```

严重级别：INFO / WARNING / ERROR
