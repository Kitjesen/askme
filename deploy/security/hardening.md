# Askme 生产环境安全加固清单

> 本文档为 Askme 语音 AI 平台的生产部署提供最低安全基线。
> 每条项目对应一个 OWASP Top 10（2021）或 ASVS 控制项。
> 部署前请逐条勾选确认。

---

## 1. 网络与传输安全

| # | 检查项 | 对应标准 | 完成 |
|---|--------|----------|------|
| 1.1 | 所有外部流量强制走 HTTPS（TLS 1.2+），禁止明文 HTTP | OWASP A05 | [ ] |
| 1.2 | Askme 服务端口（默认 8080）仅监听内网/VPN 地址，不暴露公网 | ASVS 1.1 | [ ] |
| 1.3 | 反向代理（nginx / Caddy）配置了 Strict-Transport-Security 头 | OWASP A05 | [ ] |
| 1.4 | Prometheus metrics 端口（默认 9090）不暴露公网 | ASVS 1.1 | [ ] |
| 1.5 | 使用 Web 应用防火墙（WAF）或 Cloudflare Tunnel 对外暴露 | ASVS 1.2 | [ ] |
| 1.6 | 禁用未使用的端口，仅开放 443（HTTPS）和 8080（内网代理） | ASVS 1.1 | [ ] |
